# Embedded profile fonts

The generated SVG assets embed local WOFF2 files so the profile has no runtime font requests.

- Archivo — headings, SIL Open Font License 1.1
- Manrope — display and body copy, SIL Open Font License 1.1
- Geist Mono — technical labels, SIL Open Font License 1.1
- JetBrains Mono — ASCII portrait grid, SIL Open Font License 1.1

The corresponding license texts are stored beside the font files. Font packages were obtained from Fontsource 5.3.0.
